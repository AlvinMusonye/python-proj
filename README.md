 <h>Trading Bot </h>
 <p>Stock Price Alerts & Monitoring
This is an automated trading bot that tracks major stock tickers (TSLA, AAPL, MSFT, GOOGL), fetches their real-time prices, and sends email alerts based on trading logic. It's designed to help monitor stock price movements and notify users when key conditions are met.</p>

 <h>Features</h>
 Fetch real-time stock data (TSLA, AAPL, MSFT, GOOGL)

 Send email alerts for buy/sell signals or price changes

 Monitor price thresholds or trends (customizable logic)

 Runs periodically via scheduling (e.g., cron jobs)

<h1> Technologies Used </h1>
Python (core logic)

smtplib and email for sending emails

requests or yfinance for stock data (based on implementation)
